# 蜂巢论坛签到 1.0.0

插件 ID：`fengchao_signin`。要求主程序支持 **SDK 2** 的 `forum.fengchao` 能力；Python 3.11，清单格式 1。

## 安装与配置

从「插件管理 → 插件市场」安装，安装后默认停用。

1. 在蜂巢论坛「隐秘的角落」生成专用 API Key，填入「基础设置 → API Key」并保存。
2. 可在「签到详情」点击「测试连接」验证连通性并缓存论坛账号资料。
3. 按需设置「自动签到 Cron」（默认每日 08:30）与「数据同步 Cron」（默认每日 03:00），启用插件后按 `Asia/Shanghai` 时区自动执行并自动随机错峰。
4. 开启「同步 PT 人生」时，主程序从「站点」读取已启用 PT 站点的统计数据并按配置间隔同步至论坛。
5. 开启「接收论坛通知」时，填写当前服务的 HTTPS 公网访问地址（域名需支持 IPv4 解析），保存后自动完成端到端校验与论坛回调注册，并将系统通知、回复通知与私信转发至系统已启用的通知渠道。

## 详情面板

面板仅读取本机缓存，打开界面不会额外请求论坛；展示论坛头像、等级、六维能力画像、论坛统计指标、勋章分组、当月签到日历、PT 人生摘要及签到记录，并提供「立即签到」「同步 PT 人生」「刷新信息」「测试通知」「测试连接」操作。
