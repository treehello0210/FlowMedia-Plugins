# 药丸论坛签到 1.0.0

插件 ID：`yaowan_signin`。要求主程序支持 **SDK 2** 的 `forum.yaowan` 能力；Python 3.11，清单格式 1。

## 安装与配置

从「插件管理 → 插件市场」安装，安装后默认停用。

1. 填写包含 `flarum_remember` 的论坛 Cookie，或填写论坛用户名与密码（也可同时配置）。
2. 签到时优先通过 Cookie 刷新论坛会话并完成签到；若未配置 Cookie 或 Cookie 已失效，自动回退为用户名与密码登录签到，并在成功后自动更新已保存的 Cookie。
3. 遇到站点防护拦截时可开启「启用浏览器仿真」，或开启「使用网络代理」复用系统网络代理配置。
4. 每次签到前后均实时核验论坛当前签到状态，避免重复签到或误报成功。

## 详情面板

展示当前账号、今日签到状态、连续签到天数、剩余药丸数量与历史签到记录，并提供「立即签到」「测试连接」「刷新」操作。
